# 📱 병원 휴대폰: 화면이 꺼져 있어도 알람처럼 울리게 하기 (MacroDroid)

무료 자동화 앱 **MacroDroid**가 **1분마다 웹앱에 "새 수용 요청이 있나?"를 직접 물어보고**,
있으면 **화면 켜기 → 큰 알람 벨(기본 알람음) → 웹앱 열기 → 화면 2분 유지**를 합니다.
**수용 가능/불가를 누를 때까지 1분마다 다시 울리고**, 벨은 **볼륨 −** 버튼으로 바로 끌 수 있습니다.

> 안드로이드 전용입니다 (아이폰 불가). 갤럭시 A90 5G (안드로이드 12), MacroDroid 6.0.11 에서 확인했습니다.
> Gmail 알림은 휴대폰이 잠들어 있으면 몇 분씩 늦거나 아예 오지 않는 경우가 많아서(2026-10-25 시험),
> Gmail에 기대지 않고 MacroDroid가 직접 확인하는 방식으로 바꿨습니다. Gmail 알림이 제때 오면 그때도 바로 울립니다.

## 설치 절차 (관리자가 병원에 가서 설치할 때)

- **✅** 표시는 관리자 휴대폰에서 메뉴가 있는 것을 확인한 단계입니다.
- **❓** 표시는 받는 쪽 휴대폰에서 아직 확인하지 못한 단계입니다. 화면이 조금 다를 수 있으니, 다르면 사진을 찍어 두세요.

### 0. 가져갈 것 · 미리 확인할 것

| | 내용 |
|---|---|
| 관리자 휴대폰 | MacroDroid에 **수용 요청 알람**, **알람 끄기** 가 켜져 있는 휴대폰 |
| 병원 이름 | 그 병원이 웹앱에 입력할 이름, **띄어쓰기까지 똑같이** (예: `서울대병원`) |
| 접속 코드 | 병원 관계자에게 **말로** 알려 줄 것 (이 저장소에는 없습니다) |
| 두 휴대폰 공통 | **블루투스 · 와이파이 · 위치 켜기**, 배터리 넉넉히 |

### 1. 병원 휴대폰: 웹앱 먼저 (5분)

1. 휴대폰 카메라로 README의 **웹앱 QR** 을 찍어 웹앱을 엽니다
2. **접속 코드** 입력 → **🏥 병원** 선택 → **병원 이름** 입력 → 수신 지역 선택 → 저장
3. 알림 메일 주소에는 그 병원 Gmail을 넣습니다 (선택, 없으면 비워 둠)
4. 브라우저 메뉴 → **홈 화면에 추가**

### 2. 병원 휴대폰: MacroDroid 설치와 권한 (5분)

<img src="qr-macrodroid.svg" width="160" alt="MacroDroid Play 스토어 QR">  ← 휴대폰 카메라로 찍으면 Play 스토어의 MacroDroid가 열립니다

1. 위 QR을 찍거나 Play 스토어에서 `MacroDroid` 검색 → 설치
2. MacroDroid를 열고 처음 나오는 안내 화면을 넘깁니다 (약관 동의 창이 나오면 내용을 보고 진행)
3. 데이터 공유를 묻는 창이 나오면 **거부** 를 권합니다
4. 아래 권한을 켭니다 (매크로를 받은 뒤 요청 화면이 나오기도 합니다)

   | 권한 | 위치 | 이유 |
   |---|---|---|
   | **다른 앱 위에 표시** | 설정 → 애플리케이션 → MacroDroid → 다른 앱 위에 표시 → 허용 | 화면 켜기 · 웹앱 열기 |
   | **배터리 "제한 없음"** | 설정 → 애플리케이션 → MacroDroid → 배터리 | 화면이 꺼진 동안에도 1분마다 확인 |
   | **알람 및 리마인더** | 요청 화면이 나오면 허용 | 1분 간격을 정확히 지키기 |
   | 알림 접근 (선택) | 설정 → 알림 → 고급 설정 → 기기 및 앱 알림 → MacroDroid | Gmail 알림이 오면 더 빨리 울리기 |

### 3. 매크로 넘기기: 주변 기기 공유 (매크로 1개당 1~2분)

두 휴대폰을 **30cm 안쪽** 에 둡니다.

**① 병원 휴대폰 (받는 쪽) 부터**
1. MacroDroid 아래 **매크로** 탭 ✅
2. 오른쪽 위 **⋮** → **주변 기기에서 불러오기** ✅
3. 주변 기기 · 블루투스 · 위치 권한을 물으면 **허용** ❓
4. "찾는 중" 같은 화면이 뜨면 그대로 둡니다 ❓

**② 관리자 휴대폰 (보내는 쪽)**
1. MacroDroid **매크로** 탭 → **수용 요청 알람** 을 눌러 엽니다 ✅
2. 오른쪽 위 **⋮** → **공유** → **주변 기기에 공유하기** ✅
3. 목록에 병원 휴대폰 이름이 나오면 누릅니다 ❓

**③ 병원 휴대폰**
1. 받기 확인 창 → **수락** ❓
2. 매크로 편집 화면이 열리면 오른쪽 아래 **✓ (저장)** ❓
3. 저장 뒤 **전면 광고** 가 뜨면 **닫기 / ✕** 만 누릅니다 (설치 · 열기 누르지 않기)

**④ "알람 끄기" 도 ①~③ 을 한 번 더** 반복합니다.

> 무료 버전은 매크로를 **5개까지** 만들 수 있습니다. 이 설정은 2개입니다.

### 4. 병원 휴대폰: 병원 이름 · 접속 코드 넣기 (가장 중요)

**수용 요청 알람** 의 `hospital`, `code` 는 보안 변수라서 공유할 때 값이 지워지고 **빈칸** 으로 옵니다. 빈칸이면 울리지 않습니다.

1. **매크로** 탭 → **수용 요청 알람** 을 눌러 엽니다
2. 화면 맨 아래 **전용 변수** 줄을 누르거나 위로 끌어 올려 펼칩니다 ✅
3. **hospital** → 값에 **병원 이름** (웹앱과 글자 그대로) → 확인 ❓
   - 띄어쓰기까지 웹앱과 똑같아야 합니다. 다르면 수용 가능을 눌러도 알람이 멈추지 않습니다.
4. **code** → 값에 **접속 코드** → 확인 ❓
5. 오른쪽 아래 **✓ (저장)**
6. 권한 요청 창(알람 및 리마인더 등)이 뜨면 **허용**
7. 매크로 목록에서 **수용 요청 알람**, **알람 끄기** 의 스위치가 **켜짐** 인지 확인

### 5. 시험 (3분)

1. 병원 휴대폰을 **충전기에 꽂고 화면을 끕니다**
2. 관리자가 경찰관 화면에서 그 병원 지역으로 **요청 보내기**
3. **1분 안에** 화면 켜짐 → 알람 → 웹앱 열림 이면 ✅
4. **볼륨 −** → 벨이 멈추면 ✅
5. 웹앱에서 **수용 가능** → **2분 동안 다시 안 울리면** ✅ (병원 이름이 정확하다는 뜻)

시험 결과 (2026-10-25, 관리자 휴대폰): 화면이 꺼진 상태에서 요청 후 1분 안에 화면 켜짐 · 기본 알람음 · 웹앱 열기가 실행되었고,
수용 가능을 누른 뒤에는 다시 울리지 않았습니다.

### 6. 마무리 (병원 담당자에게 알려 줄 것)

- **주 1회** MacroDroid 메인 → **"○일 남았습니다"** 확인 → **기간 연장** → 광고 **끝까지** 보기 (1편당 3일, 아래 주의 참고)
- 휴대폰은 **충전기에 꽂아 두기**
- 매크로를 다른 사람에게 공유하지 않기 (접속 코드가 들어 있음)
- 첫 설치 때 ❓ 단계의 실제 화면이 이 문서와 다르면 관리자에게 알려 주기 (문서를 고칩니다)

## 동작 방식 (참고)

```
MacroDroid (1분마다) ──▶ 웹앱 주소?check=1&code=접속코드&name=병원이름
                     ◀── NEW  (아직 수용 가능/불가로 답하지 않은 요청이 있음) → 알람
                     ◀── NONE (없음) → 아무것도 안 함
```

- 응답에는 환자 정보가 들어 있지 않습니다. 접속 코드가 틀리면 `ERR_CODE`, 병원 이름이 비어 있으면 `ERR_NAME` 이 와서 울리지 않습니다.
- '전화 확인' 을 누르면 2분 뒤 다시 울립니다 (웹앱 화면과 같은 규칙).
- 매크로 구성: 발동 = Gmail "수용 요청" 알림 **또는** 1분마다 → HTTP 요청 → `if check_result 에 NEW 포함` → 알람 음량 100% · 화면 켜기 · 기본 알람음(알람 스트림) · 웹앱 열기 · 화면 2분 유지
- 같은 내용의 매크로 파일: [`macrodroid/PAR_Alarm.macro`](macrodroid/PAR_Alarm.macro), [`macrodroid/PAR_Stop.macro`](macrodroid/PAR_Stop.macro)
  (접속 코드 없음. 휴대폰 브라우저로는 내려받기 어려워 보관용입니다)

## 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| 아무 반응이 없음 | 3단계의 **hospital · code** 를 넣었는지 확인. MacroDroid → 메인 → **시스템 로그** 에 `check_result 값 업데이트: → ERR_CODE` 가 보이면 접속 코드가 틀린 것 |
| 수용 가능을 눌렀는데 1분마다 계속 울림 | hospital 값이 웹앱의 병원 이름과 다름 (띄어쓰기 · 오타 확인) |
| 화면이 꺼져 있으면 늦게 울림 | MacroDroid 배터리 **제한 없음** 확인, 휴대폰을 **충전기에 꽂아 두기** (충전 중이 아니면 안드로이드 절전으로 확인 간격이 몇 분까지 늘 수 있음) |
| 주변 기기 목록에 상대 휴대폰이 안 보임 | 두 휴대폰 모두 블루투스 · 위치 · 와이파이 켜기, 받는 쪽에서 **주변 기기에서 불러오기** 화면을 먼저 열어 두기, 더 가까이 두기 |
| 주변 기기 공유 자체가 안 됨 | 다른 방법(파일 등)으로 바꿔야 합니다. 화면 사진과 함께 관리자에게 알려 주세요 |
| 매크로를 더 만들 수 없다고 나옴 | 무료 버전은 5개까지 — 안 쓰는 매크로를 지우기 |
| 휴대폰 재시작 직후 동작 안 함 | MacroDroid를 한 번 열어 확인 |
| 다른 알람(아침 알람)도 너무 큼 | 매크로가 알람 음량을 100%로 올린 채 둠 → 음량 값 설정을 60~80%로 낮추기 |

## ⚠ 주의

- **접속 코드가 매크로 안에 들어갑니다.** 병원 관계자 휴대폰에만 넣고, 매크로를 다른 사람에게 공유하지 마세요.
- 병원 휴대폰 1대가 하루 약 1,440번(1분마다) 웹앱에 확인합니다. 병원이 아주 많아지면 확인 간격을 늘려야 할 수 있습니다.
- **무료 버전은 사용 기간을 계속 연장해야 합니다 (매크로 5개 이하여도 마찬가지).**
  MacroDroid 6.0.11 앱 안내: 무료 사용 일수가 끝나면 *"일수를 추가해야 계속 무료로 사용할 수 있습니다"* — 광고를 끝까지 보거나 설문에 답하면 일수가 추가됩니다.
  - 메인 화면 아래 **"무료 버전 · ○일 남았습니다"** 를 **주 1회** 확인하고, 줄어들었으면 **기간 연장** → 광고를 **끝까지** 봅니다 (중간에 건너뛰면 추가되지 않음)
  - 병원마다 **확인 담당자**를 정해 두세요. 잊으면 응급 알람이 조용히 멈출 수 있습니다
  - 연장한 뒤에는 시험 요청으로 울리는지 한 번 확인합니다
  - "데이터 파트너에 익명 사용정보 공유" 에 동의하면 무제한이 되지만, 업무용 휴대폰의 정보가 외부로 가므로 권하지 않습니다
  - 챙기기 어렵다면 **Pro(휴대폰마다 1회 ₩10,000)** 로 바꾸면 광고와 기간 제한이 없어집니다
- PC로 설정을 도왔다면 휴대폰 **설정 → 개발자 옵션 → USB 디버깅** 을 끄세요.
