# 📱 병원 휴대폰: 화면이 꺼져 있어도 알람처럼 울리게 하기 (MacroDroid)

Gmail 알림만으로는 알림음이 한 번 짧게 울리고 끝납니다.
무료 자동화 앱 **MacroDroid**를 쓰면 "수용 요청" 메일이 왔을 때
**화면 켜기 → 큰 알람 벨 → 웹앱 열기 → 화면 2분 유지**를 자동으로 하고,
**볼륨 − 버튼**으로 벨을 바로 끌 수 있습니다.

> 안드로이드 전용입니다. 아이폰은 이런 자동화가 불가능합니다.
> 갤럭시 A90 5G (안드로이드 12), MacroDroid 6.0.11 에서 실제로 설정·확인한 순서입니다.
> 메뉴 이름은 기종·앱 버전에 따라 조금 다를 수 있습니다.

## 0. 먼저 확인할 것

1. **병원 알림 Gmail 주소가 관리자 계정과 달라야 합니다.**
   웹앱을 배포한 Google 계정(메일을 보내는 계정)과 같은 주소로 받으면, Gmail이 "내가 보낸 메일"로 보고 **휴대폰 알림을 띄우지 않습니다.**
   → 병원용 Gmail을 따로 만들고, 웹앱 **설정**에서 그 주소를 넣습니다.
2. 휴대폰 **Gmail 앱**에 그 계정을 추가하고 설정 → 계정 → **알림: 모두** 로 둡니다.
3. 웹앱에서 경찰관이 요청을 보냈을 때 휴대폰 Gmail에 알림이 오는지 먼저 확인합니다.
   (메일이 스팸·프로모션 탭에 들어가면 알림이 오지 않으니 "기본"으로 옮기세요.)

## 1. MacroDroid 설치와 권한

1. Play 스토어에서 **MacroDroid** 설치
2. 아래 권한을 모두 허용합니다 (매크로를 만들다 보면 요청 화면이 나옵니다).
   | 권한 | 위치 | 이유 |
   |---|---|---|
   | **알림 접근** | 설정 → 알림 → 고급 설정 → 기기 및 앱 알림 → MacroDroid | Gmail 알림 감지 |
   | **다른 앱 위에 표시** | 설정 → 애플리케이션 → MacroDroid → 다른 앱 위에 표시 | 화면 켜기·웹앱 열기 |
   | **배터리 "제한 없음"** | 설정 → 애플리케이션 → MacroDroid → 배터리 | 화면이 꺼진 동안에도 동작 |

## 2. (선택) 알람 벨소리 파일 준비

MacroDroid 기본 소리 목록은 짧은 알림음뿐입니다. 길고 큰 벨을 쓰려면 소리 파일을 하나 준비합니다.

- 휴대폰에 있는 아무 mp3/ogg 알람 소리를 **내 파일 → 내장 저장공간 → Alarms** 폴더에 넣어 둡니다.
- 시험 설정에서는 삼성 기본 벨소리 `Classic_Bell.ogg` 를 `Alarms/PAR_Alarm.ogg` 로 복사해 사용했습니다 (약 4초).
  PC에 adb가 있다면:
  ```
  adb shell "mkdir -p /sdcard/Alarms && cp /system/media/audio/ringtones/Classic_Bell.ogg /sdcard/Alarms/PAR_Alarm.ogg"
  ```

## 3. 매크로 ① "수용 요청 알람" 만들기

MacroDroid → 아래 **매크로** 탭 → **＋ (새 매크로)**

### 발동 조건 (빨간 칸 ＋)
1. **기기 관련 변동** → **알림** → **알림을 받으면** → 확인
2. **앱 선택** → 검색창에 `gmail` → **Gmail** 체크 → 확인
3. 텍스트 내용: **포함하면** 선택 → `수용 요청` 입력
   (알림 문구 예: `🚨 [수용 요청] 서울 · 외상 — 요청 2147-5T4`)
4. 확인

> 참고: PC(adb)로 입력할 때는 한글을 칠 수 없어서 **RegEx 사용 + 일치하면** 으로
> `(?s).*수용.요청.*` 를 넣었습니다. 휴대폰에서 직접 입력한다면 위처럼 "포함하면 + 수용 요청"이면 됩니다.

### 동작 (파란 칸 ＋, 위에서부터 순서대로)
| 순서 | 메뉴 | 설정 |
|---|---|---|
| 1 | **음량 → 음량 값 설정** | **알람** 체크 → 슬라이더 **100%** (너무 크면 60~80%) |
| 2 | **화면 → 화면 켜기/끄기** | **화면 켜기** |
| 3 | **미디어 → 소리 재생/정지** | **[파일 선택]** → `Alarms/PAR_Alarm.ogg` (또는 목록의 소리) · **출력 오디오 스트림: 알람** |
| 4 | **애플리케이션 → 웹사이트 열기** | 웹앱 주소(`https://script.google.com/macros/s/.../exec`) 입력, "HTTP GET" 은 체크하지 않음 |
| 5 | **화면 → 기기 켜짐 상태 유지** | **기기 켜짐 상태 유지 사용** → **화면 켜둠** · **일정 시간동안** · **2분** |

- 출력 스트림을 **알람**으로 해야 무음·진동 모드에서도 크게 울립니다.
- 웹앱이 열리고 화면을 한 번 터치하면, 수용 가능/불가를 누를 때까지 웹앱 경보가 3초마다 반복됩니다.

### 저장
위쪽 **매크로 이름 입력** 에 `수용 요청 알람` → 오른쪽 아래 **저장(✓)**.

## 4. 매크로 ② "알람 끄기" (볼륨 − 버튼으로 벨 멈춤)

벨 동작(③)과 반대 동작이라 **반드시 별도 매크로**로 만듭니다.
(한 매크로에 트리거를 추가하면, 볼륨을 낮출 때 오히려 알람이 울립니다.)

1. **＋ (새 매크로)**
2. 발동 조건: **사용자 입력 → 음량 버튼을 누르면** → 안내 확인 →
   **음량 값이 달라지면** (접근성 권한 불필요) → **음량을 낮추면** → **변경된 음량 값 유지**
3. 동작: **미디어 → 소리 재생/정지 → [재생 중인 미디어 중지]** → 확인
4. 이름 `알람 끄기` → 저장

> 화면이 켜져 있을 때 동작합니다. 알람이 오면 화면이 2분간 켜져 있으므로 그 사이에 **볼륨 −** 를 누르면 됩니다.
> 웹앱의 반복 "삐삐삐" 는 웹앱에서 **수용 가능/불가** 를 눌러야 멈춥니다 ('전화 확인'은 2분간만 멈춤).

## 5. 시험

1. 매크로 목록에서 두 매크로의 스위치가 **켜짐**인지 확인
2. 병원 휴대폰 화면을 끔
3. PC(경찰관 화면)에서 병원 지역(예: 서울)으로 **요청 보내기**
4. 1분 안에 **화면 켜짐 → 벨 → 웹앱 열림** 이면 성공, **볼륨 −** 로 벨이 멈추는지 확인

시험 결과 (2026-10-22): 알림 도착 1초 안에 화면 켜짐·알람 음량 최대·벨 재생·웹앱 열기가 실행되었고,
볼륨 − 를 누르자 벨이 바로 멈췄습니다.

## 6. 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| 메일은 오는데 알림이 안 뜸 | 받는 주소가 관리자(보내는) 계정과 같음 → 병원용 Gmail 사용. 스팸·프로모션 탭이면 "기본"으로 이동 |
| 아무 반응이 없음 | **비행기 모드**·인터넷 끊김 확인. MacroDroid 배터리 "제한 없음" 확인 |
| 휴대폰 재시작 직후 동작 안 함 | 부팅 직후 잠시 MacroDroid가 준비되지 않을 수 있음. MacroDroid를 한 번 열어 확인 |
| 매크로를 저장했는데 사라진 것 같음 | 무료 버전은 저장 뒤 **전면 광고**가 뜸. 광고의 ✕/⏭ 로 닫고(설치 버튼 누르지 않기) 매크로 목록에서 확인 |
| 다른 알람(아침 알람)도 너무 큼 | 매크로가 알람 음량을 올린 채 둠 → ① 의 음량 값을 낮추거나 알람 후 원래 값으로 되돌리는 동작 추가 |
| 모든 앱 알림마다 화면이 켜짐 | "모든 앱" 알림으로 화면을 켜는 다른 매크로가 있으면 끄기 |
| 웹앱 대신 브라우저 설정 화면이 뜸 | 삼성 인터넷에 열어 둔 설정 화면을 닫아 두기 |

## ⚠ MacroDroid 무료 버전 사용 기간

무료 버전은 메인 화면에 **"무료 버전 · N일 남았습니다"** 가 표시되고,
기간이 끝나기 전에 광고를 보고 연장하거나 **Pro(1회 결제)** 로 바꾸지 않으면 매크로가 멈출 수 있습니다.
응급 알림용으로 쓴다면 기간을 꼭 확인하세요.

## 다 끝난 뒤

PC로 설정을 도왔다면 휴대폰 **설정 → 개발자 옵션 → USB 디버깅** 을 끄세요.
